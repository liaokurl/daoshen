# Telegram 通知串接包（車干製）

讓任何 App（刀神×葵哥、選股 App…）把訊號推到你的 Telegram。

|---|---|

想分開聊天室：到 @BotFather 再 `/newbot` 開一個新的機器人，換掉權杖就好（聊天室編號要重新抓）。

## 三種串接方式（照選股 App 的類型挑一個）

| 選股 App 是… | 用哪個檔案 | 權杖放哪 |
|---|---|---|
| Google Apps Script（試算表、GAS 網頁） | `telegram.gs` | 直接填在檔案最上面 |
| Node.js 伺服器／GitHub Actions 排程 | `telegram.mjs` | 環境變數或 GitHub Secrets：`TG_TOKEN`、`TG_CHAT` |
| Python 程式 | `telegram.py` | 環境變數：`TG_TOKEN`、`TG_CHAT` |
| **純網頁（GitHub Pages 那種靜態網站）** | **不能直接傳**，權杖會被任何人看到 | 改由 Google Apps Script 代傳：網頁呼叫 GAS 網址，GAS 用 `telegram.gs` 發送（刀神 App 就是這樣做） |

## 呼叫方式

```js
tgSend("進場多單 46,888", "🎯 目標1 46,908\n🎯 目標2 46,968\n🛑 帶狀翻空就出");
```

- 第一個參數是**標題**，會變成粗體放在最上面，手機通知預覽就看得到 → 把最重要的（方向、點位、股票代號）放這裡。
- 第二個參數是內容，用 `\n` 換行。
- 第三個參數（可省略）是連結，例如個股頁或 App 網址。

建議的訊息格式（前幾行一眼看懂）：

```
【選股】🚀 進場｜2327 國巨 534
🎯 目標 540.66（MH-H，+1.2%）
🛑 停損 528.66（MH-L，−1.0%）
形態 A+（90 分）｜次級強撐打樁
```

## 給 Codex 的指令（直接複製貼上）

> 請在這個專案加入 Telegram 通知。使用附件 `telegram.gs`（或 `telegram.mjs`／`telegram.py`，依專案語言）裡的 `tgSend(title, message, link)`。
> 規則：
> 1. 權杖與聊天室編號不要寫死在會公開的程式碼裡；Node／Python 讀環境變數 `TG_TOKEN`、`TG_CHAT`，GitHub Actions 用 Secrets。
> 2. 如果是純前端網頁，不可直接呼叫 Telegram API，必須經由 Google Apps Script 或伺服器代傳。
> 3. 每次出現選股訊號時發一則：標題＝「方向 + 股票代號名稱 + 價格」，內容依序是目標、停損、評級與理由。
> 4. 同一檔股票同一個訊號 30 分鐘內不要重複發。
> 5. 通知失敗只記錄警告，不可讓主程式中斷。

## 注意事項

- 同一個聊天室每秒最多約 1 則，一次大量訊號請合併成一則（例如「今日選股 5 檔」列表）。
- 單則上限 4096 字，模組已自動截斷到 4000。
- 想要靜音時段：在 Telegram 對該聊天長按 →「靜音」，或在程式裡加時間判斷。
- 權杖外洩時：到 @BotFather → `/revoke` 換新權杖，再把新的填回各個 App。
